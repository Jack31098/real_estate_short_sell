HPP 的 callable 优先股，下跌潜力是否更大？

目前没有足够证据判定优先股的可实现空头收益更大。常规资产价值下降先侵蚀普通股；优先股还可因收益率上升、分红延迟或偿付风险重估而下跌。后者需要覆盖约 8.2%／年的股息补偿和未知借券费。

这里比较的是 HPP 普通股与 4.750% Series C 累计可赎回优先股（HPP-PC / HPP.PRC）。Callable 指发行人有赎回权。它是永续证券，2026-11-16 是首次普通可赎回日，不是必须偿还的到期日。

什么条件才更值得研究优先股空头？

假设普通股一年后从 $11.88 降到 $8，年借券费 3%，净情景收益 29.7%。优先股年借券费 5%、继续派息时，需要降到约 $8.26，即要求收益率约 14.38%，才能达到同样的净收益。

若优先股仅重估到 12% 收益率，价格约 $9.90，净收益约 18.4%；若重估到 16%，价格约 $7.42，净收益约 35.5%。后者能超过上述普通股情景，但需要解释为何优先股风险会被重估到这个程度。

这不是给两种证券指定同一经济状态。还需用同一套租约、资产价值、现金流与融资情景，联合约束普通股退出价和优先股退出收益率。
